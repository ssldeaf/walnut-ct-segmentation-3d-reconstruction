## **Заметка по проекту от 15.02.2026**

### Основные вопросы на данном этапе:

- Какие данные считать целевыми для нашей задачи(например, КТ ореха или КТ органов человека).
- Основываясь на целевых данных, решить, какие методы применять в ходе разработки решения.
- Определение черного ящика проекта (с чем мы работаем и что должно получаться на выходе рабочего решения)

### Контекст:

В теме проекта напрямую упоминаются данные КТ и понимание их сути важно для последующего выполнения проекта.

```
КТ (Компьютерная томография) - используется для изучения внутренней структуры объектов при помощи рентгеновского излучения. КТ показывает некую плотность материала внутри объекта по серии рентгеновских проекций, полученных под разными углами.
```

Контекст на данный момент — разработка метода векторизации данных компьютерной томографии (КТ) с возможным применением в задачах анализа как биологических объектов(например, внутренних органов человека), так и более простых структур (например, грецкого ореха).

На входе КТ получатся 3D-объем вокселей с числом, пропорциональным ослаблению рентгена. Это связано с реализацией числа вокселя: число в вокселе = значение в единицах Хаунсфилда (HU), которое прямо связано с тем, насколько сильно этот участок ослабил рентгеновский луч.

Конкретное представление же данного объема зависит от выбранного источника данных и целевого объекта. В общем смысле можно представить как стек последовательных двумерных срезов (поперечных сечений объекта). Именно эти данные и сейчас будем считать как входные для проекта.

На выходе должен получаться триангулированный меш целевого объекта, полученный из входных КТ данных. Меш представляет собой набор точек и ребер которые ограничивают объект, те его векторное представление в 3х мерном пространстве.

### Черный ящик:

**Вход**: Трёхмерный КТ объём объекта (стек поперечных срезов), ориентация, метаданные сканирования.

**Выход**: Векторное 3D представление геометрии объекта в виде набора меш-моделей.
